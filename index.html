Resumen del Proyecto

Este proyecto consiste en la implementación de una base de datos para una universidad utilizando MySQL, incluyendo:

  • Creación de la estructura de la base de datos
  • Inserción de datos de prueba
  • Consultas simples y complejas
  • Consultas multitabla
  • Consultas resumen y estadísticas
  • Subconsultas avanzadas
