Introducción

Este proyecto implementa un sistema completo de base de datos para una universidad utilizando MySQL, desarrollado como parte de la Estancia I en la Universidad Politécnica de Juventino Rosas.

Autoría

Objetivos

El proyecto tiene como principales objetivos:

  • Modelar una base de datos relacional para una institución universitaria
  • Implementar consultas SQL de complejidad variable
  • Documentar el proceso de desarrollo
  • Proporcionar ejemplos prácticos de operaciones CRUD
  • Generar reportes académicos complejos
  • Establecer relaciones adecuadas entre entidades académicas
  • Optimizar el rendimiento de las consultas

Estructura de la Base de Datos

El sistema de base de datos está diseñado para gestionar toda la información académica de una universidad, incluyendo:

SQL 
CREATE DATABASE universidad CHARACTER SET utf8mb4;
USE universidad;

-- Tabla persona (alumnos y profesores)
CREATE TABLE persona (
    id INT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    nif VARCHAR(9) UNIQUE,
    nombre VARCHAR(25) NOT NULL,
    apellido1 VARCHAR(50) NOT NULL,
    apellido2 VARCHAR(50),
    ciudad VARCHAR(25) NOT NULL,
    direccion VARCHAR(50) NOT NULL,
    telefono VARCHAR(9),
    fecha_nacimiento DATE NOT NULL,
    sexo ENUM('H', 'M') NOT NULL,
    tipo ENUM('alumno', 'profesor') NOT NULL
);

-- Tabla departamento
CREATE TABLE departamento (
    id INT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(50) NOT NULL
);

-- Tabla profesor
CREATE TABLE profesor (
    id_profesor INT UNSIGNED PRIMARY KEY,
    id_departamento INT UNSIGNED NOT NULL,
    FOREIGN KEY (id_profesor) REFERENCES persona(id),
    FOREIGN KEY (id_departamento) REFERENCES departamento(id)
);

Tablas Principales

El sistema contiene las siguientes tablas principales:

Tabla Descripción Relaciones
persona Datos de alumnos y profesores Relacionada con profesor, alumno_se_matricula_asignatura
departamento Áreas académicas Relacionada con profesor, asignatura
profesor Vinculación profesores-departamentos Relacionada con persona, departamento, asignatura
grado Programas académicos Relacionada con asignatura
asignatura Materias ofertadas Relacionada con grado, profesor, alumno_se_matricula_asignatura
curso_escolar Periodos académicos Relacionada con alumno_se_matricula_asignatura

Consultas Básicas

Listados básicos

SQL 
-- Alumnos ordenados alfabéticamente
SELECT nombre, apellido1, apellido2
FROM persona
WHERE tipo = 'alumno'
ORDER BY apellido1, apellido2, nombre;

-- Alumnos sin teléfono registrado
SELECT nombre, apellido1, apellido2
FROM persona
WHERE tipo = 'alumno' AND telefono IS NULL;

-- Alumnos nacidos en 1999
SELECT nombre, apellido1, apellido2
FROM persona
WHERE tipo = 'alumno' AND YEAR(fecha_nacimiento) = 1999;

Filtros avanzados

SQL 
-- Profesores sin teléfono y NIF que termina en K
SELECT nombre, apellido1, apellido2
FROM persona
WHERE tipo = 'profesor'
AND telefono IS NULL
AND nif LIKE '%K';

-- Asignaturas del primer cuatrimestre, tercer curso del grado 7
SELECT a.nombre
FROM asignatura a
WHERE a.cuatrimestre = 1
AND a.curso = 3
AND a.id_grado = 7;

Ejemplos Completos

Alumnas en Ingeniería Informática

SQL 
SELECT DISTINCT p.nombre, p.apellido1, p.apellido2
FROM persona p
JOIN alumno_se_matricula_asignatura ama ON p.id = ama.id_alumno
JOIN asignatura a ON ama.id_asignatura = a.id
JOIN grado g ON a.id_grado = g.id
WHERE p.sexo = 'M' 
AND g.nombre = 'Grado en Ingeniería Informática (Plan 2015)';

Estadísticas por Departamento

SQL 
SELECT d.nombre AS departamento, 
       COUNT(DISTINCT p.id_profesor) AS num_profesores,
       COUNT(DISTINCT a.id) AS num_asignaturas
FROM departamento d
LEFT JOIN profesor p ON d.id = p.id_departamento
LEFT JOIN asignatura a ON p.id_profesor = a.id_profesor
GROUP BY d.nombre
ORDER BY num_profesores DESC, num_asignaturas DESC;
