# Proyecto de Base de Datos Universidad

![Logo Universidad](assets/img/logo.png)

Este proyecto consiste en la creación y consulta de una base de datos para una universidad, implementado en MySQL como parte de la Estancia I en la Universidad Politécnica de Juventino Rosas.

## Autor
- **Jorge Gutiérrez Mancera**
- Tutor: **Luis Rey Lara González**

## Estructura del Proyecto

1. **Creación de la base de datos**: Scripts SQL para crear la estructura y poblar las tablas
2. **Consultas sobre una tabla**: Operaciones básicas de selección
3. **Consultas multitabla**: Composición interna y externa
4. **Consultas resumen**: Agregaciones y estadísticas
5. **Subconsultas**: Consultas anidadas avanzadas
